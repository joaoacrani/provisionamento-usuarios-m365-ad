# Política de segurança

## Como relatar uma vulnerabilidade

Se você encontrou uma falha de segurança neste projeto, **não abra uma issue pública**. Use o relato privado do GitHub: na aba **Security** do repositório, clique em **Report a vulnerability**. Descreva o que encontrou, como reproduzir e o impacto que você enxerga. A resposta costuma sair em alguns dias.

## O que esperar

- Este é um projeto de portfólio, mantido por uma pessoa. Não há versões antigas com suporte: a correção vai para a versão atual.
- Todos os dados de exemplo (nomes, domínios, redes, usuários) são fictícios. **Não envie credenciais, tokens ou dados reais** em issues, pull requests ou relatos.
- Se a falha envolver um ambiente real que usa este código, corrija o ambiente antes de divulgar detalhes.
